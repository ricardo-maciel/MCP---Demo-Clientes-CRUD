# Demo Clientes CRUD - End-to-End MuleSoft & MCP Ecosystem

Este repositório contém a esteira completa de design, implementação, governança, implantação e consumo inteligente da API **Demo Clientes CRUD**. O projeto foi concebido como uma Prova de Conceito (POC) técnica para demonstrar a fusão entre a arquitetura tradicional baseada em APIs e os novos ecossistemas de agentes de Inteligência Artificial utilizando o **Model Context Protocol (MCP)**.
